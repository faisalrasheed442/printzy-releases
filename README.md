# Printzy — the free replacement for Microsoft Publisher

**Printzy** opens your Microsoft Publisher (`.pub`) files and makes flyers, newsletters, certificates,
menus, business cards, labels and posters, ready to print. Free, with no account and no subscription,
and it works offline. For Windows, and Linux as an AppImage.

**Status:** in development. The first version's downloads will appear under **Releases** here and on
[zylio.net](https://zylio.net), with a full user guide.
